# 缺料自动合成

## 要解决什么

材料库没有成品、但有可合成原料时，女仆不必干等玩家手工合成——工程可选择自动把原料合成进库再继续施工。

## 期望行为

- 工程开关「缺料自动合成」，**默认关**。
- 开启后：每次判定材料库无对应成品时，用库内物品按**工作台 + 切石机 + 熔炉/高炉 + 锯子类切割**配方**虚拟递归**合成；成功则成品（含配方溢出产出）入库，再走原扣料/放置。
- 失败：与现规则一致（库为 0 才气泡索要），无额外失败提示。
- 中途往库里补下级原料后，下一轮检查会再试合成。
- 原料只扣材料库；不扣女仆/玩家背包；世界无需真实工作台/切石机/熔炉。

## 触发、条件与边界

- **触发：** 工程开关开着，且材料库对该施工材料计数为 0（即将放置/领料/缺料再检查时）。
- **边界：** 被忽略的材料类型不合成；烟熏/营火/锻造等不做；熔炉路径**不计燃料**（虚拟烧炼）；一次产出多于需求时允许溢出留库；库位装不下全部产出时，**只要有部分入库即算成功**（溢出丢弃）。
- **边界：** 多配方优先「库内原料已够、少递归」；有深度上限与环检测。
- **边界：** 工作台**成型配方**按格列出同种材料时，会合并为总需求数量（例如告示牌 6 木板 + 1 棍），避免只合成出 1 根原木的 4 木板就误判失败。
- **边界：** 开启自动合成时，合成失败**不**按材料永久拉黑；**仓库内容没变时跨 tick 也不再重解**；每拍最多尝试约 2 次求解，避免第一种无配方材料单独把服务端卡数秒。往库里补料或库内容变化后会再试。
- **边界：** 配方原料是标签时，只试库里已有的种类，或当前库能直接凑齐原料的种类（优先原版）。其余替代物不展开。单次求解有步数上限；超限与「合不成」相同，库内容不变就不再重试。每拍 2 次求解的限制仍然有效，不能代替这一条。

## 当前完成度与已知缺口

- **已有：** 求解器 + 材料源包装 + Hub 开关；部分入库成功；开启时失败不永久拉黑，**同库内容下记住失败**、补料后再试；成型配方多格同材料合并计数；配方索引含工作台、切石机、**熔炉/高炉**，以及锯子/切木机等单输入切割类（woodcutting）。标签不再整表展开；单次求解有步数上限。
- **缺口：** 烟熏/营火/锻造；真工作台/熔炉演出。
