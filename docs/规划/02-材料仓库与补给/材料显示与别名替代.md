# 材料显示与别名替代

## 要解决什么

蓝图里常有**没有物品形态**或**难以堆叠获取**的方块；材料页与女仆索要必须显示**玩家能认、能掏**的东西，并对**注定不施工**或**免费生成**的类型诚实标注。

## 期望行为

**别名替代（显示与扣料统一）**

- **无物品方块**（如洞穴藤蔓某段、植株段等）：材料库与气泡改认**可获取物品**，例如**发光浆果**。  
- **高草丛 / 大型蕨 / 高海草**：改认**小麦种子**或**海草**等可获取替代。  
- 玩家往库内存替代物即可推进施工；界面显示名称/icon 让玩家知道要备什么。

**液体免费生成（不进材料清单）**

- **水 / 流动水 / 岩浆 / 流动岩浆**：**不**出现在材料页、缺料统计与创造补料；玩家无需备桶。  
- 施工过程中**不放**水/岩浆格子，女仆也不去领。含水的台阶、楼梯等先放**不含水**的样子。世界格里已经是水或岩浆时，待建方块**直接换上**，不先挖（挖开会把同一摊流体留住）。正下方还是待灌的水/岩浆时，实心方块照常放；要有水才站得住的方块等灌完再放；踩不稳流体的附着方块跳过。女仆领不到的剩余格（够不着、延迟互等）与水/岩浆同一波由工程收尾放置：固体**扣库**，水/岩浆仍**免费**。之后按原版流动。  
- 与「自动忽略」不同：忽略是跳过不放；液体是**留到收尾再放、免费生成**。

**泥土 / 草方块互认（世界已满足 + 库料互通）**

- 蓝图待建为**泥土**或**草方块**时：世界里已是其中任一 → **视为已满足，不挖不换**。  
- 材料检测 / 领单查料 / Hub「已有」：库中**泥土与草方块互相顶数**（有泥土可领草方块单，反之亦然；优先扣与蓝图同名的那一种）。  
- **不含**粗泥土、缠根泥土等其它土壤变体。

**自动忽略（不施工）**

以下类型（含同类）**自动忽略**，不参与放置与扣料，应在清单或报告区可辨：

- 发光地衣、垂根、大垂滴叶茎  
- 火、灵魂火、气泡柱  
- 活塞臂  
- （以及版本改动中列明的同类规则）

**与手动忽略区别**

- **自动忽略：** 规则层不支持或不可获取，系统默认跳过。  
- **手动忽略：** 玩家主动选择不管某可施工材料。

## 触发、条件与边界

- **触发：** 导入蓝图生成清单时映射别名；渲染材料页时显示替代 icon/名；缺料判定时按材料键而非原始方块 id alone。  
- **边界：** 别名表随版本扩充，新 mod 方块可能暂显示为「未知/缺失」直至补规则。  
- **边界：** 液体免费目前仅原版水/岩浆（含流动态）；其它 mod 液体暂不扩。  
- **边界：** 替代物必须**可堆叠进材料库**；若仅实体/不可堆叠则进报告区而非强行索要。  
- **不做：** 让玩家在 UI 里自定义「有物品但嫌麻烦」的全局别名表（系统别名仍由版本维护）。  
- **做：** 对**注册表缺失**的方块，允许在本工程内指定替代（见 [缺失材料替换](./缺失材料替换.md)）。

## 当前完成度与已知缺口

- **已有：** 浆果/种子/海草等别名；**水/岩浆免费直接生成**（不进材料页）；世界里已是水/岩浆的格子可直接换成待建方块；**泥土↔草方块**世界互认与库料互通；自动忽略列表（版本改动条目）。  
- **已有：** 工程级「缺失材料替换」（独立页：蓝图标红 + 右键选替代；计入材料库；女仆用替代物建造）。  
- **待核实：** 新地形/植物 mod 方块覆盖率。  
- **缺口：** 别名与忽略规则需与工程报告区「缺失示例名」文案一致，避免显示浆果却报告藤蔓名（体验 polish）。
