# 材料仓库与补给

## 1. 定位与目标

材料仓库是施工终端的**补给中枢**：承接蓝图清单、存放玩家投入的物品、按规则**扣料**给女仆放置，并在缺料时**不无理停工**。  
**成功标准：** 玩家能往终端库塞够料（或创造一键补料），女仆持续施工；材料页数字与真实消耗一致，重进存档**不回档**。

## 2. 玩家体验 / 玩法流程

1. 导入蓝图后，**选址与材料页**看到还需哪些方块、各需多少。  
2. 打开终端**材料库**（100 页 × 每页 3 行 = **2700 格**），滚轮**整页翻页**存料。  
3. 女仆放置时**先扣终端库、再扣女仆背包**。  
4. 某物品库内为 **0** 时女仆才**气泡索要**；局部队列有货就继续放，不因「这一批不够整批」全停。  
5. 工程页可**忽略/恢复**某材料类型；创造模式可**一键按清单补料**（与材料页剩余一致，**追加不覆盖**，多工程可累加）。  
6. 无物品方块显示**可获取替代**；施工页材料不足时有**底部提示**。

## 3. 内容边界

### 做

- 2700 格材料库与整页滚轮翻页（翻页后当前页立刻可见）；可按显示名/id 搜索过滤（不重排真实库）  
- 手持终端材料库挂世界存档、物品只留钥匙（不塞进背包同步）  
- 拒收有内含物的容器（空容器可放）  
- 扣料顺序：终端库 → 女仆背包  
- 缺料气泡（库为 0 才索要）、局部队列不断工；缺料时钉在当前格、不跟随，大约每 10 秒重扫材料库  
- 忽略/恢复材料、创造一键补料（追加、多工程累加）  
- 工程可选「缺料自动合成」（工作台+切石机+熔炉/高炉+锯子类、虚拟递归、默认关）  
- 别名替代显示（浆果、种子、海草等）与自动忽略不施工类型  
- **注册表缺失方块**：工程内玩家指定替代，计入材料库并由女仆建造  
- 进度/已消耗/还需数量与放置计数同步；重进持久化  
- 材料页还需 0 时不再索要；施工页不足提示  

### 不做

- 自动从玩家主背包**远距离吸料**（除非另有计划；当前以终端库+女仆背包为准）  
- 跨维度/跨世界材料传送  
- **本模组内**不做经济/商城采购补料（由硬依赖附属「施工队：多多采购」等联动；本模组提供缺料快照、入库、Hub 材料页按钮挂钩，「无货成品 → 可购合成原料」只读拆解 API——标签里有能买的就买原版、单行搜索有上限、超限该行无货，以及采购侧单原料最多 3 跳、**按本单缺料目标过滤**的虚拟库存增强）  
- 烟熏/营火/锻造等非上述配方的自动合成（见 [缺料自动合成](./缺料自动合成.md)）

## 6. 后续规划与优先级

1. **维持：** 重进不回档、多工程补料不覆盖——易回归，优先保。  
2. **体验：** 材料不足提示与报告区文案统一（让玩家知道「库空」还是「被忽略」）。  
3. **扩展（低）：** 更多 mod 方块的别名/忽略表，随版本改动追加，不单独升优先级除非玩家反馈集中。  
4. **文档：** 与终端体验、主计划 M5 材料验收项互链。
