# 缺失材料替换

## 要解决什么

蓝图里常有**当前游戏注册表没有的方块**（报告区红字）；系统只能跳过。需要让玩家为本工程指定「用哪种现有方块代替」，并纳入材料库与女仆施工。

## 期望行为

- 工程页入口「缺失材料替换」→ 列表每一行：缺失注册 id、「在蓝图显示」、「替换为」、已映射时可「清除」。  
- **在蓝图显示：** 幽灵预览里只画出该缺失 id 的格子并标红；其它蓝图材料不一起出现。同时只看一种；再点同一行关闭。  
- **替换为：** 进入选择模式，右键世界方块选定**类型**；放置时尽量保留蓝图原属性。  
- 映射后：材料清单按替代物计数，女仆用替代物建造；报告区不再把该 id 算作未处理缺失。  
- **仅本工程**持久化；实体缺失仍跳过。  
- **仅未开工 / 已暂停**可改或清除；开工中禁用。

## 触发、条件与边界

- **触发：** Hub 缺失替换页；选择模式右键实体方块。  
- **边界：** 替代物须为当前可放置方块；点空气无效。
- **边界：** 「在蓝图显示」须已确认选址，否则只提示先选址、不画空预览。与选址预览互斥：进入选址会关掉缺失高亮并只留选址提示；点「蓝图显示」或「替换为」时不再占用选址点击。  
- **边界：** 从**手持终端**开启的高亮与该终端绑定：手上不再是施工终端（换槽、丢下、收进背包后手里没有）即自动关闭，提示与红色过滤一起消失，不留看不见的开关。从**已放置终端**开启的不按手持判断，仍需再点同一行关闭。  
- **边界：** 打开别工程的缺失替换页、或该 id 已不在当前工程缺失列表时，高亮自动取消；登出与换维度一并清掉地址预览和高亮，避免旧存档状态带进新世界。  
- **边界：** 不改写蓝图文件；不回溯已放置格。  
- **不做：** 缺失实体替换；全局/跨工程共用表；从投影解析中文名（无模组语言包时仍显示注册 id）。

## 当前完成度与已知缺口

- **已有：** 工程映射、材料/任务/创造补料接入、Hub 页、选择模式、蓝图标红。  
- **待核实：** 进游戏对复杂楼梯/朝向属性套用效果；暂停中改映射后工单重建。
