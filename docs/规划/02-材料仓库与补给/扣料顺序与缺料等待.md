# 扣料顺序与缺料等待

## 要解决什么

放置方块时**统一、可预期地消耗材料**，并在缺料时**少打扰、少误停**——有货就继续干，真正没货才向玩家喊。

## 期望行为

**扣料顺序**

1. **终端材料库**  
2. **施工女仆背包**  

任一来源有足够数量即扣减并完成放置（含工程级强制放置、寻路失败后的直接放置等**特殊放置**，扣料规则与正常放置**一致**）。

**缺料与气泡**

- 工程若开启「缺料自动合成」：库无成品时先尝试用库内原料虚拟合成（见 [缺料自动合成](./缺料自动合成.md)），成功后再继续。  
- 女仆**气泡索要**条件：该物品在**终端材料库中的数量为 0**（不是「还不够下一批」就喊）。  
- **材料页显示还需 0** 时：即使队列里还有历史待铺格，也**不再**气泡索要同种材料（与重进后进度合并逻辑一致）。
- **缺料等待**时女仆**停在原地**（仍在工地语境内），气泡提示即可；**不**跟随主人、**不**因主人走远而传送过去，也**不**因卡住救援被拉开。等待期间大约每 **10 秒**重扫一次材料库，界面里新放入的物品会被认到并继续施工。

**局部队列（不断工）**

- 女仆按层/按格维护**局部待放队列**。  
- 若当前批次某种材料**不够放满整批**，但库或背包里**仍有该物品**，则**有货就放**，**不因本批不够而整批停工**。  
- 仅当该来源确实无货且满足索要条件时，才等待玩家补给。

**界面提示**

- **施工页**在材料库不足以支撑后续放置时，**底部**给出材料不足提示（与气泡互补，适合玩家盯 Hub 时不看女仆）。

## 触发、条件与边界

- **触发：** 女仆（或工程级兜底）成功放置一格 → 扣相应物品 1（或方块等价数量）。  
- **边界：** 被**忽略**的材料类型不扣料、不放置（见 [忽略材料与创造补料](./忽略材料与创造补料.md)）。  
- **边界：** 别名替代物品在扣料时按**同一材料键**匹配（见 [材料显示与别名替代](./材料显示与别名替代.md)）。  
- **不做：** 从玩家主背包自动抽料（未在现行规则内）。

## 当前完成度与已知缺口

- **已有：** 先库后背包；库 0 才气泡；局部队列不断工；还需 0 不索要；施工页底部不足提示；强制/直接放置同样扣库；缺料钉在当前格、不跟随；缺料等待大约每 10 秒重扫材料库。  
- **待核实：** 多女仆同时扣同一物品时的竞态是否极少发生且结果可接受。  
- **缺口：** 无核心规则缺口。
