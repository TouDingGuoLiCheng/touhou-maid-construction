# 超时与卡住

## 要解决什么

搭架过程中无进展时要有升级手段（继续搭、传送、放弃），避免女仆吊在半空或反复失败。

## 期望行为

**玩家侧**：脚手架附近卡住约 1 秒内应有换位或继续搭架；攀爬放架失败一次就会传送回工位继续施工。

**女仆侧**：
- **脚手架附近 0.75 秒无进展** → 升级：**搭架 / 传送 / 放弃**（与 03 同层换格、让出配合）
- **攀爬放架失败 1 次** → 可**传送工位**
- **施工任务摔落免疫**（脚手架阶段同样适用）
- 与 03 个人卡住：**邻域 3 秒 / 工位旁 1 秒 / 20 秒无放置** 等传送规则并行生效（见 [寻路与卡住恢复](../03-女仆施工行为/寻路与卡住恢复.md)）

## 触发、条件与边界

| 信号 | 响应 |
|------|------|
| 架区 0.75s 无进展 | 升级搭架 → 仍不行则传送或放弃让出 |
| 攀爬放架失败 1 次 | 传送至几何工位 |
| 路线偏离或下格不可放 | 重算路线（见 [路线规划](./路线规划.md)） |
| 规划失败且无工位/够不着 | 记下失败并换同层其它可放格（见 [03-寻路与卡住恢复](../03-女仆施工行为/寻路与卡住恢复.md)） |
| 长期仍不可达 | 交 03 unreachable / 工程兜底 |

- **放弃让出**：释放认领格，避免独占；不等于标 DONE
- **传送**不改变「先架后隔空」总顺序，仅恢复可执行态
- **无脚手架材料**时仍会尝试规划；失败后按上表换格，缺架气泡见 [材料与缺架](./材料与缺架.md)

## 当前完成度与已知缺口

- **已有**：0.75s 升级链、攀爬失败传送、摔落免疫、规划失败换同层格
- **缺口**：升级顺序在「省料续柱」与「直接传送」之间的观感调参；整片悬空且无架材料时需玩家补架或地基
