# 路线规划

## 要解决什么

脚手架应走「竖塔 + 横伸」的省料、可攀爬路线，且路线稳定，只在必要时重算。

## 期望行为

**玩家侧**：女仆沿建筑边起柱、到高度再横铺，像人工搭架子；少出现反复拆改同一段路。

**女仆侧**：
- 结构：**竖塔 + 横伸**
- **起柱优先贴建筑边**；柱顶被挡时**外侧外扩**
- **模组施工脚手架互为支撑**
- **续搭已有柱 vs 新建柱**：选**省材料**方案
- **路线锁定**；仅当**偏离**或**下一格放不下**才**重算**
- **关键节点**使用**原版寻路**检验可达性
- **竖向提前铺**；**横向到柱顶再铺**
- 到达目标高度后**改向工位**，不把末端实心工位当待铺架

## 触发、条件与边界

- 规划输入：目标待建格、可选几何工位、现有临时柱/蓝图边
- 重算条件：女仆明显偏离锁定路线；或计划下一架位被占/不可放；全量重算**无**拍额度限制，可立刻重规划
- 与放置：横伸终点应对准可站立/可触及工位，而非待铺蓝图格本身（若该格为实心工位）
- 与 03：同层其它可放格仍优先于无谓长架（见 [工位选择与放置](../03-女仆施工行为/工位选择与放置.md)）

## 当前完成度与已知缺口

- **已有**：竖塔横伸、贴边起柱、路线锁定、关键节点寻路、全量重算无额度限制
- **待核实**：复杂镂空建筑外扩柱的省料与美观平衡；多女仆同时全量重规划的 tick 成本
