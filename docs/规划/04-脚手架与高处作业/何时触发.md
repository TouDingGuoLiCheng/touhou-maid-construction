# 何时触发

## 要解决什么

明确「什么时候该搭脚手架」，以及与寻路、隔空之间的先后顺序，避免该架不架或不该隔空却隔空。

## 期望行为

**玩家侧**：女仆够不着时会先搭架再施工；只有架子搭好仍到不了才可能出现库放置/隔空。

**女仆侧**：
- **够不着**或**站位失败**后 → **先脚手架**（见下方「低层例外」）
- **原版寻路预检失败** → 先走向几何工位，仍不够再进入脚手架流程（见 03 [寻路与卡住恢复](../03-女仆施工行为/寻路与卡住恢复.md)）
- **缺架**时：气泡提示，**不因此隔空**
- **有架仍不可达** → 才进入 unreachable / 库放置链路（见 03 [强制放置与工程级兜底](../03-女仆施工行为/强制放置与工程级兜底.md)）
- **垂直差 >2 且到不了工位**：**不得**误判为跳过脚手架（低层例外除外）

## 触发、条件与边界

| 阶段 | 规则 |
|------|------|
| 1. 触及/工位 | 能在邻格工位触及+视线 → 直接放置，不搭架 |
| 2. 寻路预检 | 失败 → 走向几何工位 |
| 3. 脚手架 | 仍够不着或站位失败 → 搭临时架 |
| 4. 缺架 | 仅气泡+等待材料，**不隔空** |
| 5. 仍不可达 | mark unreachable 等 → 允许库放置（严格条件） |

**低层例外（相对待建第一层）**：起始层滤掉下层后，待建第一层记为第 1 层。正在建第 **1、2** 层时**禁用脚手架规划**，够不着走无架恢复（寻路/工位/隔空等）；从第 **3** 层起恢复正常搭架。

- 临时架使用模组**「施工脚手架」标记方块**，外观同原版脚手架
- **不把路径末端实心工位**当作待铺脚手架格；**到达高度后改向工位**

## 当前完成度与已知缺口

- **已有**：先架后隔空、缺架不隔空、垂直差>2 保护、相对第 1–2 层禁用脚手架规划
- **缺口**：部分「站位失败」与「够不着」边界 case 仍见 [内容边界与已知缺口](./内容边界与已知缺口.md)
