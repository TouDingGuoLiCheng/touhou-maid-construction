# 内容边界与已知缺口

## 要解决什么

汇总脚手架模块** deliberately 不做**的事，以及当前仍影响体验的已知缺口，供掌舵排期。

## 期望行为

掌舵人读本文能判断：某现象是「按设计不做」还是「待修缺口」。

## 触发、条件与边界

### 明确不做

- **不**把路径末端**实心工位**当作待铺脚手架
- **不**为缺外部地形/支撑垫脚手架当地基（标失败跳过，归 03）
- **不**因**缺架**而隔空（须补料或换格）
- **不**在完工回收时**强制加载**未加载区块
- **不**回收**蓝图自带**脚手架

### 与 03 的交界

- **垂直差 >2 且到不了工位**：禁止误判「跳过脚手架」——属硬边界
- **有架仍不可达**才隔空；**idle 不触发**隔空
- 同格寻路失败计数、VAULT_PLACE 冷却等以 03 为准

### 已知缺口 / 待核实

| 缺口 | 说明 |
|------|------|
| 误判跳过脚手架 | 个别高度差/工位几何仍可能过早放弃搭架；见搭建范围计划 |
| 外扩柱观感 | 柱顶被挡时外侧外扩可能显得「架出去太远」 |
| 路线锁定 vs 动态障碍 | 玩家中途改动邻格导致锁定路线失效的重算频率 |
| 未加载区块上的临时架 | 完工不强制加载；该区块加载后需再点一次完工才会扫到 |
| 复杂门与寻路节点 | 关键节点原版寻路与特殊门交互；见原版寻路改造计划 |

## 当前完成度与已知缺口

- **总体**：主干可用，边角与观感仍在三项脚手架相关计划中验收
- **优先**：误判修复 > 寻路节点；未加载区块上的临时架要等加载后再点一次完工
