# 脚手架与高处作业

## 1. 定位与目标

本模块定义女仆在**够不着或站不稳**时如何用模组「施工脚手架」临时登高，以及搭完、卡死、缺架、完工回收的全流程。成功标准：先架后放、有架仍不可达才隔空；路线稳定省料；完工只拆女仆临时架，蓝图自带架保留。

## 2. 玩家体验 / 玩法流程

女仆够不着时会搭外观同原版的施工脚手架（标记方块区分临时架）；缺架时头顶气泡提示。玩家看到竖塔+横伸的合理路线，少出现把路径末端实心工位误当待铺架。点完工后临时架回收，包括贴在建筑外侧的柱子；未加载区块不强制加载。

## 3. 内容边界

### 做
- 触发：够不着/站位失败后**先脚手架**；缺架气泡、**不因此隔空**
- **低层例外**：相对待建第一层（起始层滤后）的第 1、2 层不规划脚手架；第 3 层起正常
- 规划：竖塔+横伸；贴建筑边起柱；路线锁定与重算条件；关键节点原版寻路
- 超时：0.75 秒无进展升级；攀爬放架失败 1 次可传送工位；摔落免疫
- 材料：续搭已有柱 vs 新建柱选省材料；模组架互为支撑
- 完工：只回收女仆临时架（含建筑外侧、账本没记下的柱子）；未加载区块不强制加载

### 不做
- 不把**路径末端实心工位**当待铺架
- 不为缺外部地形垫脚手架当地基（缺地形标失败跳过，见 03）
- 完工回收**不强制加载**未加载区块
- **不为相对第 1、2 施工层规划临时架**

## 4. 当前完成度与缺口

- **已有**：标记方块临时架、触发顺序、路线规划主干、缺架气泡、摔落免疫、完工选择性回收、低层禁用脚手架规划、全量重算无额度限制
- **半成品**：极端外扩柱、误判跳过脚手架的边角（见 [内容边界与已知缺口](./内容边界与已知缺口.md)）
