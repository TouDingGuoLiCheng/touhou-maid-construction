# 完工回收

## 要解决什么

工程 DONE 后临时脚手架应被收回，但不误拆蓝图设计里的脚手架，且不因区块未加载而卡死回收逻辑。

## 期望行为

**玩家侧**：点完工后，女仆搭的临时架消失，包括贴在建筑外侧、看起来在「施工区域外」的柱子；蓝图里本来就有的脚手架方块仍在。

**女仆侧**：
- **只回收女仆搭建的临时架**（标记方块）
- **蓝图自带脚手架保留**
- 账本没记下的临时架（例如重进世界后）也会在工地周围已加载的范围内被清扫
- 与 03 同步：**解绑女仆**、工程标 **DONE**

## 触发、条件与边界

- 触发：玩家点完工 / 工程完成判定（见 [03-破坏补放与完成判定](../03-女仆施工行为/破坏补放与完成判定.md)）
- **完工回收不强制加载区块**
- **已加载区块**：按账本回收，并清扫工地占地外扩范围内仍立着的临时架（含建筑外侧柱子）
- **未加载区块**：账本记录清除；那些区块上的临时架要等加载后再次点完工才会被扫到

## 当前完成度与已知缺口

- **已有**：临时/蓝图架区分、不强制加载、完工时清扫占地外扩范围内已加载的临时架（含账本遗漏的外侧柱）
- **缺口**：未加载区块上的临时架，要等该区块加载后再次点完工才会被扫到
