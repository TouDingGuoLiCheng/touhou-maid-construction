# 选址幽灵预览与确认

## 要解决什么

让玩家在**确认落点之前**就能看清蓝图长什么样、哪里会冲突；确认之后仍能**对照轮廓**施工，开工后只看**还没放上的格**，减少「放错位置才发现」的挫败感。

## 期望行为

**选址中**

- 世界内显示半透明**真实方块色**幽灵（不是单色占位框）。  
- 与现有方块/规则冲突的格**标红**；存在冲突时**禁止开工**（须先改位置、开覆盖或调整蓝图）。  
- 玩家可 **中键固定** 当前预览姿态，再执行**确认落点**。

**确认后**

- **不因确认而清空**幽灵；继续显示完整轮廓，便于对照地形与女仆作业范围。

**开工后**

- 轮廓切换为：只显示**尚未放置**的格（已放格不再高亮）。  
- 玩家可**手动关闭预览**；工程**完工**后预览消失。

**取消 / 结束**

- 完工，或玩家手动关预览，轮廓才结束显示。

## 触发、条件与边界

- **进入：** 选址与材料页发起选址模式。  
- **固定：** 中键固定预览 → 确认落点写入工程。  
- **开工：** 施工页启动女仆施工后进入「仅未放格」模式。  
- **边界：** 冲突判定与贴地/覆盖规则见 [贴地覆盖与朝向旋转](./贴地覆盖与朝向旋转.md)、[蓝图读取与冲突检测](./蓝图读取与冲突检测.md)。  
- **边界：** 幽灵为客户端预览 + 服务端落点一致；重进后锚点轮廓随工程恢复，但「轮廓开/关」按客户端偏好记住，不会因重开游戏或重开终端被强制开回。
- **边界：** 选址中始终显示完整蓝图（冲突标红），不会被「缺失方块蓝图显示」滤成只剩一种格子；两边提示也不叠在一起。进入选址会关掉缺失高亮。

## 当前完成度与已知缺口

- **已有：** 真实色幽灵 + 冲突红（T1）；确认后保留轮廓；开工后仅未放格；手动关预览且跨重启记住（T1）。大型投影的方块外观只生成一次，之后跟着镜头移动；冲突红在落点或附近方块变化时更新。  
- **待核实：** 视距边缘是否仍清晰。  
- **缺口：** 与「工程完工」判定的 UI 联动若 M5 前为 stub，需与模块 03 完工判定最终一致。
