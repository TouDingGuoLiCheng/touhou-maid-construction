# 贴地覆盖与朝向旋转

## 要解决什么

让蓝图**贴合地形**（而不是悬空或埋进地里），并在需要时**覆盖地表植被**；同时让玩家能**旋转朝向**，使建筑与地形、通道对齐。

## 期望行为

**贴地向上**

- 选址时蓝图整体**贴地**，并沿竖直方向**向上**生长（「贴地向上」），适应起伏地形的基础落点逻辑。  
- 玩家移动预览时，落点随光标/规则更新，幽灵实时反映高度变化。

**覆盖地表**

- 工程/选址侧可开启**允许覆盖**（或与「覆盖地表」等价的开关）。  
- 开启后：草方块、泥土、沙子等**可覆盖类地表**按规则**不判冲突**，女仆施工时会走清障/覆盖流程（模块 06）。  
- 未开启时：这些格可能标红，无法确认。

**忽略重叠**

- 与「覆盖地表」**独立**的工程开关（默认关）。  
- 开启后：蓝图范围内任意**可破坏**重叠方块不判冲突，女仆施工时同样可清障入库。  
- **基岩等不可破坏方块**仍硬冲突，无法确认选址，也不会被挖。  
- 「覆盖地表」仍只控制点击锚点是贴地替换格还是贴地向上。

**起始层**

- 相对蓝图底的层号 N（默认 0）：`Y < N` 的蓝图格**完全不存在于本工程**（不幽灵、不算料、不领单、不挡完工）。  
- **仅开工前**可改；开工/暂停后锁定。  
- 用于跳过投影里多余的地下垫土等低层，避免女仆去挖/放够不着的深处。

**朝向旋转**

- **进入选址**时，按玩家**面朝方向**自动设置蓝图初始转向。  
- **左右方向键**（或等价按键）每次再转 **90°**。  
- 旋转与贴地、冲突检测同时生效；中键固定时锁定当前位置与朝向。

## 触发、条件与边界

- **触发：** 进入选址模式；切换覆盖/忽略重叠开关；按键旋转。  
- **边界：** 「覆盖地表」不等于「任意方块都可覆盖」——树木、矿石、玩家建筑等仍可能冲突，见模块 06；若要清空任意可破坏重叠，请开「忽略重叠」。  
- **边界：** 旋转仅绕竖直轴（Yaw），不涵盖仰俯翻转蓝图（除非产品另定）。  
- **不做：** 逐格手动升降蓝图锚点（当前无此玩法）。

## 当前完成度与已知缺口

- **已有：** 贴地向上选址；允许覆盖后草地上可确认无冲突落点（T0）；**忽略重叠**独立开关（可破坏重叠可确认+清障，基岩仍冲突）；**起始层**跳过蓝图低层；进入选址按面朝自动转向 + 左右键 90° + 中键固定确认。  
- **待核实：** 极陡斜坡、浮空/水下落点的体验是否需额外提示（待游戏内走查）。  
- **缺口：** 无（与模块 06「可覆盖 / 忽略重叠」边界已在文档对齐）。
