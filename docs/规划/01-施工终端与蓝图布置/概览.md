# 施工终端与蓝图布置

## 1. 定位与目标

施工终端是玩家与 `.litematic` 蓝图施工之间的**唯一指挥台**：导入投影、选落点、看冲突、确认开工，并统筹材料与女仆进度。  
**成功标准：** 玩家不记指令、不翻代码，也能完成「手持终端 → 导入蓝图 → 贴地/覆盖选址 → 确认 → 看轮廓与报告 → 交给女仆施工」全流程。

模组：**车万女仆：施工队**，Minecraft **1.20.1 Forge**，硬依赖**车万女仆**；读取 **`.litematic`** 蓝图进行施工。

## 2. 玩家体验 / 玩法流程

1. 工作台合成（上下木板、中间铁锭/红石/铁锭）或创造栏获得**手持施工终端**；右键直接开 Hub（放置功能已移除）。  
2. **右键手持终端或旧存档遗留的终端方块**打开 **Hub**（约占屏幕 70%×70% 的暖木色三页界面）。  
3. 在工程页**导入** `.litematic`（点选文件 / 文件夹 / 列表；拖放框仅为外观，**不做真 OS 拖进游戏**）。  
4. 切到选址与材料页：**幽灵预览**真实方块色，冲突标红；贴地向上、可选覆盖地表；按朝向与按键微调旋转；**中键固定**后确认落点。  
5. 确认后仍可看轮廓；**开工后**只显示尚未放置的格；工程页查看报告与材料；施工页看女仆与进度。

## 3. 内容边界

### 做

- 工作台合成获得施工终端；仅手持形态（放置功能已移除）；右键开 Hub  
- 手持形态的**材料库**挂在世界存档，物品只留钥匙（不把 2700 格写进背包同步）  
- Hub 三页：工程管理 / 选址与材料 / 施工女仆与进度  
- `.litematic` 读取、工程列表、选址幽灵、冲突检测、贴地/覆盖、朝向旋转  
- 确认前后与开工后的轮廓显示状态机  
- 终端方块**免疫岩浆等环境破坏**  
- 工程页**报告区**（缺失方块示例、放置失败说明、已知限制）

### 不做

- 系统资源管理器**真拖放**进 MC 窗口  
- 非 `.litematic` 的其它投影格式（除非另开计划）  
- 本模块内的女仆寻路、脚手架、扣料细则（见模块 02、03、04）

## 6. 后续规划与优先级

1. **维持：** 终端体验已落地能力稳定，避免回归（右键、覆盖选址、轮廓状态机）。  
2. **衔接 M5+：** 女仆施工与终端进度/报告区字段保持一致，避免「界面显示已完工、世界未完工」类分裂。  
3. **低优先：** 真 OS 拖放导入（明确不做，除非产品改口）。  
4. **文档：** 与 `下一步的计划-车万女仆：施工队-终端体验.md` 验收项对齐，用户目视通过后勾选归档。
