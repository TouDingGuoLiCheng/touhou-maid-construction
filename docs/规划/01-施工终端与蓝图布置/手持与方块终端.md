# 手持与方块终端

## 要解决什么

让玩家用**一种熟悉的物品**完成「随身携带 → 右键指挥施工」，并保证终端在工地环境中**不被岩浆等轻易毁掉**。

## 期望行为

**玩家侧**

- 可用工作台合成获得**施工终端**：上下两行任意木板，中间一排铁锭 / 红石 / 铁锭。  
- 手持**施工终端**物品，**不再能放置成方块**（放置会误碰落地终端的仓库钥匙，已整段移除）；右键直接打开 Hub。  
- **右键已放置的终端方块**（旧存档遗留）同样打开 Hub；不应出现「放了却打不开」的阻塞。  
- 终端方块对**岩浆等环境破坏免疫**，长期放在工地仍可用。  
- 手持形态承载全部操作（如工程列表、创造补料等，细节在 Hub 与材料模块）；旧存档已放置的方块仍是持久化的工地锚点，但本版不再提供新的放置入口。

**系统侧**

- 同一套工程数据可绑定到**该位置的方块实体**（或等价持久化），重进存档后仍可恢复。  
- **手持**形态：材料库挂在**世界存档**，物品只带钥匙。物品不再放置，因此没有「放置时拷贝仓库」这一步；旧存档里已放置的方块各自记自己的钥匙，挖起仍写回存档、不换号。工程列表跟物品走。同一存档的旧手持 NBT / 旧落地终端会在加载时迁库，不另开空库。

## 触发、条件与边界

- **触发：** 工作台合成（或创造栏）获得物品 → 右键打开 Hub。  
- **边界：** 本主题不含 Hub 内各页细则、不含女仆 AI；仅「获得方式 + 两种形态 + 打开入口 + 存活规则」。  
- **边界：** 放置功能已移除：手持或创造模式右键都只开 Hub，不再生成方块，也不会改写任何仓库钥匙。  
- **边界：** 创造中键复制已绑定钥匙的落地终端：复制品只带钥匙；未迁移的旧方块仍可带上原 `Items`。  
- **边界：** 把终端物品带到**另一个存档**对不上钥匙，库会空（本版不做跨存档随身整库）。  
- **不做：** 终端不作为脚手架或建筑材料参与蓝图本身（除非另有装饰性计划）。

## 当前完成度与已知缺口

- **已有：** 工作台合成表；仅手持形态（放置已移除）；右键开 Hub（终端体验 T0）；旧存档落地终端仍可右键使用；终端方块免疫岩浆等环境破坏；手持材料库挂世界存档、物品只留钥匙；挖起写回同一钥匙；旧存档同世界迁库。  
- **待核实：** 用户本地目视终验（终端体验 T5 最后一项勾选）；满库手持时帧数对比；旧存档手持满库进游戏后材料仍在。  
- **缺口：** 丢失钥匙后的孤儿库清理（本版不做）；跨存档随身整库（明确不做）。
