# Hub 三页与工程管理

## 要解决什么

把「导入蓝图、选点备料、盯女仆干活」拆成**三页清晰工作流**，避免一个界面堆满所有信息；工程页还要承担**诊断报告**，让玩家知道卡在哪。

## 期望行为

**Hub 结构（三页）**

| 页 | 职责 |
|----|------|
| **工程管理** | 工程列表、导入入口、单工程设置、**报告区** |
| **选址与材料** | 进入/退出选址、覆盖地表 / 忽略重叠 / **起始层**、材料清单与材料库入口 |
| **施工女仆与进度** | 绑定女仆、开工/暂停、放置进度、材料不足提示 |

**工程管理页**

- **导入：** 方框 + 图标 + 短文案；支持 **点选文件**、**选文件夹**、**已有 `.litematic` 列表**三种入口；外观像「拖放区」，但**不是**把文件从 OS 拖进游戏窗口。  
- 导入成功后工程出现在列表，可选中编辑。  
- **报告区**展示：**缺失方块示例名**、**放置失败说明**、**已知限制**（让玩家区分「缺料」「冲突」「规则不支持」）。

**界面气质**

- 窗口约 **70%×70%** 屏幕；暖木色 + 羊皮纸衬底；PixelLab 整图工作台背景，中间留白给控件。

## 触发、条件与边界

- **触发：** 右键终端方块 → Hub 打开；切页不改变已选工程（除非玩家切换工程项）。  
- **边界：** 材料库 2700 格、扣料顺序等在模块 02；女仆领单在模块 03。  
- **不做：** 真 OS 拖放；本页不实现女仆寻路细节。

## 当前完成度与已知缺口

- **已有：** 三页 Hub；导入三入口（T3）；大窗暖色 UI（T2）；工程报告区；PixelLab 背景与定向方块（T4）。  
- **待核实：** 不同 GUI Scale 下可读性（T2 验收）；用户目视全流程（T5）。  
- **缺口：** 报告区文案需随施工行为持续丰富（与模块 03 放置失败原因对齐），属**内容维护**而非界面缺失。
