# 清障时机与挖掘顺序

## 要解决什么

女仆在覆盖模式下被地形挡住时，**何时**挖、**先挖哪**、**每 tick 挖多少**，才能继续当前放置任务而不卡头、不空转。

## 期望行为

**女仆侧**：
- 仅在挡**当前任务**的视线、站位或寻路时挖——不是预先整盒铲平。  
- **瞬间**破坏（无单独挖土阶段 UI）。  
- 每 tick 最多约 **4 格**，避免一 tick 挖穿半座山。  

**挖掘顺序**（对齐原版寻路净空）：
1. **脚位 + 头顶**两格（身体占用）  
2. 沿**视线**方向，挖命中格及其**上方一格**（**两格高通道**）  

**放置前**：目标格若是可覆盖地形 → 先按清障/入库规则处理，再盖蓝图块。

## 触发、条件与边界

| 挂点 | 说明 |
|------|------|
| MOVING / 寻路 | 路径被盒内可覆盖块挡住 |
| 找不到工位 | 站位被挡 |
| 放置前 | 目标格或可覆盖占用 |
| 每 tick 身体检查 | 头/脚卡在可覆盖块内 |

**不挖**：覆盖与忽略重叠都关闭、盒外、非可覆盖（忽略重叠未开时）、脚手架、该格已经是蓝图要的方块。蓝图空气格不单独整盒拆除。

**不新增**独立 `DIGGING` 相位；挖开后走现有寻路 / 脚手架 / 传送链路。

## 当前完成度与已知缺口

- **已有**：挂点接入、顺序与 tick 上限、放置前清可覆盖格  
- **需进游戏回归**：视线被泥土/石头挡住时是否稳定挖开并继续放；多女仆是否互挖已放格
