# 可覆盖判定范围

## 要解决什么

覆盖地表模式下，哪些世界方块算「可以埋进蓝图、不算硬冲突、必要时可被女仆挖掉」——与**贴地向上（非覆盖）**、**玩家建筑**、**盒外地形**划清界限。

## 期望行为

**玩家侧**：开启覆盖后，选址时盒内的草、花、未去皮树、树叶等**不标红**；关闭覆盖时这些仍可能冲突。

**系统侧**：选址冲突检测与施工清障**共用同一套**可覆盖判定，避免「选址能过、施工不挖」或相反。

## 触发、条件与边界

### 算可覆盖（覆盖模式开启时，且在蓝图 AABB 内）

- 常规地形：泥土、石头、沙子、 gravel 等原有可覆盖类  
- **花草植株**：花朵标签、灌木类方块、可替换类植株（不单靠 `canBeReplaced` 一种判定）  
- **树木**：**未去皮**原木/木头（`logs` 且不含 `stripped`）、**树叶**（`leaves`）  

### 不算可覆盖 / 仍冲突

- **盒外**任意方块  
- **基岩**等不可破坏类  
- **去皮**原木、玩家实心建筑（非可覆盖判定）  
- **已正确放置**的蓝图格（**同一种方块**即算，不因朝向/形状/含水差而清障）  
- **脚手架**（模组临时架与蓝图架均不当作可覆盖清障目标）  
- **空气**（选址冲突不计；施工时不因「蓝图是空气」就整盒拆世界里的草方块或石头）  

### 模式开关

| 模式 | 行为 |
|------|------|
| 覆盖地表 **关** + 忽略重叠 **关** | 不挖；树/草等按原冲突规则；贴地向上不挖地 |
| 覆盖地表 **开** | 盒内可覆盖 → 可冲突豁免 + 可清障（锚点改为替换点击格） |
| 忽略重叠 **开** | 盒内任意可破坏重叠 → 可冲突豁免 + 可清障；基岩等不可破坏仍硬冲突 |
| 两开关可独立组合 | 覆盖只管锚点/可覆盖类；忽略管更广的可破坏重叠 |

### 蓝图空气格

蓝图标成空气的格子不建造，开工后也不整盒拆除。世界里的草方块、石头和其它地表留着，直到它们挡住女仆的寻路、站位或身体，并满足覆盖地表或忽略重叠的清障条件。该格已经是蓝图要的方块则不拆。选址冲突仍跳过空气格。

## 当前完成度与已知缺口

- **已有**：判定扩展至花草/树叶/未去皮原木；选址与清障共用规则；**忽略重叠**独立开关  
- **需进游戏回归**：覆盖关时树仍冲突；开覆盖时野花簇/玫瑰丛等不再红字；开忽略时可破坏建筑可确认；基岩仍冲突
