# 地形清障与可覆盖物

## 1. 定位与目标

当玩家在终端开启**覆盖地表**时，蓝图范围内的可覆盖地形（土石、花草、未去皮原木与树叶等）不再一律算硬冲突；施工女仆在**挡视线、挡站位、挡寻路**时会**瞬间挖开**这些方块，战利品进**终端材料库**，再继续放置蓝图块。

**成功标准：** 覆盖模式下埋进草/土/树的蓝图能施工；非覆盖模式不挖挡路地形。女仆没走到的地表留着，已经是蓝图要的方块不拆。

## 2. 玩家体验 / 玩法流程

1. 选址页开启「允许覆盖地表」→ 盒内花草/树叶/未去皮树干等**不标红冲突**。  
2. 确认开工 → 女仆若被地形挡住，会**先挖通道**（脚与头顶、沿视线两格高）再寻路/搭架/放置。  
3. 挖掉的方块**进材料库**（满则掉在挖点附近）。  
4. 关闭覆盖、且未开忽略重叠时：贴地向上**不挖挡路地形**；树干/树叶等仍按冲突规则处理。  
5. 蓝图标成空气的格子不建造，也不在开工后整盒拆除。挡住寻路的地表仍按上面的近身清障处理。

## 3. 内容边界

### 做

- **覆盖地表**开启时清可覆盖地表；**忽略重叠**开启时清盒内可破坏挡路块。两个都关则不挖  
- 范围：蓝图 **AABB 包围盒内**且判定为**可覆盖地形**  
- 时机：挡**当前任务**的视线 / 站位 / 寻路时  
- 顺序：先清**脚+头顶**两格身体占用，再沿**视线**挖**两格高通道**；每 tick 上限约 **4 格**  
- 放置目标格本身若是可覆盖地形 → **先入库再盖**蓝图块  
- 可覆盖类型含：泥土/石头/沙等、花草植株（花朵标签与灌木类、可替换植株）、**未去皮**原木/木头、树叶等  
- 该格世界里**已经是蓝图要的方块**（同种即算，泥土与草方块互认）则不拆

### 不做

- **贴地向上（非覆盖、且未忽略重叠）**时挖挡路地形  
- 开工后**整盒扫描**拆空气格上的草方块、石头或其它地表  
- 挖**盒外**、**基岩**、**脚手架**、**已是蓝图所需的格子**  
- 为缺外部地形**垫脚手架当地基**（缺地形标失败跳过，见 03）  
- 单独新增「挖土阶段」动画相位（仍走现有 MOVING / 放置前挂点）

## 4. 当前完成度与缺口

| 方面 | 状态 |
|------|------|
| 可覆盖判定扩展（花草/树叶/未去皮原木） | 已有 |
| 选址冲突与清障共用可覆盖规则 | 已有 |
| 清障挂点、每 tick 上限、身体占用优先 | 已有 |
| 挖掉入库、满库掉地 | 已有（逻辑） |
| 开工后整盒拆空气格上的草方块/石头 | 不做；只在寻路等被挡住时拆 |
| 覆盖关闭时不清障、不挖树 | **需进游戏回归** |
| 开覆盖时野花簇等不再红字冲突 | **需进游戏回归** |
| 多女仆互挖已放好蓝图格 | 同种方块不再当缺块/清障目标；极端属性边界仍需进游戏看一眼 |
