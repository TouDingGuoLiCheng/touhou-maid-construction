# 入库与安全通道

## 要解决什么

挖掉的方块**去哪**、材料库**满了怎么办**，以及**两格高通道**如何避免女仆「只挖前方/脚下、头卡进方块里」。

## 期望行为

**入库**：
- 清障挖掉的方块 → **终端材料库**（与玩家手动存入同一库）。  
- 库**满** → 剩余掉落物生成在**挖点附近**（不 silently 消失）。  

**安全通道**：
- 必须先处理**脚 + 头顶**两格身体占用，再沿视线挖通道。  
- 通道为**两格高**，与原版寻路净空一致，避免只挖一格高导致头卡进地形。  

**与放置衔接**：
- 目标格是可覆盖地形时：**先入库（或满库掉地）再放置**蓝图块。  

## 触发、条件与边界

- 仅覆盖模式 + 盒内可覆盖 + 当前任务需要时触发入库逻辑。  
- 入库不改变「先库后背包」的**放置扣料**顺序（见 02）。  
- 清障**不**替女仆远程补材料；只是回收挖下的方块。  

## 当前完成度与已知缺口

- **已有**：入库与满库掉地逻辑；身体占用优先 + 两格高通道设计；放置前强制清除不符块同样入库；材料源包装层（自动合成 / 库存索引）下入库仍生效  
- **需进游戏回归**：大工程连续清障时库满掉地是否可接受；极端堆叠 mod 物品入库表现
