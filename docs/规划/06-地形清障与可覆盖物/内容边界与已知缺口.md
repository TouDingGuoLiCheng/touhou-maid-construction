# 内容边界与已知缺口

## 要解决什么

汇总清障模块**明确不做**的事，以及**仍待验收/待核实**的缺口，避免与脚手架垫地基、隔空放置等其它模块混淆。

## 期望行为

掌舵人读本文即可判断：某现象是清障范围内该修的，还是应去 03/04 模块看。

## 触发、条件与边界

### 明确不做

| 项 | 说明 |
|----|------|
| 非覆盖模式挖地 | 贴地向上不挖挡路地形；忽略重叠也关着时，空气格上的草方块/石头同样不拆 |
| 盒外清障 | 仅限蓝图 AABB 内 |
| 脚手架当地基 | 缺外部地形 → 标失败跳过（03） |
| 整盒预清 | 不预先铲平整盒，施工中也不扫描拆空气格上的草方块和石头 |
| 改原版 pathfinder | 挖开后仍用现有寻路 |
| 逐格清障账本 | 运行时盒内判定，不持久化逐格挖土表 |

### 已知缺口 / 待验收

| 项 | 状态 |
|----|------|
| 覆盖关：树/草仍冲突、不清障 | 需进游戏 |
| 覆盖开：野花簇等不红字 | 需进游戏 |
| 覆盖开：挖树入库并继续施工 | 需进游戏 |
| 多女仆不互挖已放蓝图格 | 需进游戏 |
| 完工后再进不被拉回旧工地 | 与 05 联验 |
| 极端 mod 植物是否都进可覆盖表 | 随反馈扩展 |

## 当前完成度与已知缺口

- **核心逻辑**：阶段 1–2 计划项 largely 已完成（见根目录清障计划勾选）  
- **阶段 3 回归**：多项仍为 `[ ]`，本模块完成度标为**中高**而非「全绿」
