# 女仆施工行为

## 1. 定位与目标

本模块定义施工女仆「接到蓝图工程后怎么干活」：分层领单、选工位、寻路开门、放置/清障、卡住恢复、工程级兜底，以及点完工后的解绑与进度正确性。成功标准：多女仆同层协作不抢格；够得着就放、够不着先脚手架；长时间无进展有明确兜底，不隔空死循环。

## 2. 玩家体验 / 玩法流程

玩家确认工程开工后，绑定女仆自动留在工地、取消坐下、进入工作态并关闭拾取；材料优先从库扣，缺架会气泡提示；缺料时钉在当前格等待补料（不跟随乱跑）；暂停或完工后恢复跟随与拾取。玩家主要看进度与气泡，不必手把手指挥站位。

## 3. 内容边界

### 做
- 分层建造、触及优先局部队列、多女仆同层领单与防抢/让出
- 工位以「能放置」为准（触及+视线），放置触及约 6 格
- 原版寻路预检、路径同步到女仆脑以开门；卡住传送与强制放置兜底
- 放置前强制清除非蓝图占用物；材料先库后背包；施工任务摔落免疫与窒息救援
- 工程级强制放置与全员 IDLE 兜底；够不着的收尾格与水/岩浆同一波由工程放置；点完工 DONE、解绑、回收临时脚手架

### 不做
- 不为缺地形/外部支撑垫地基（标失败跳过）
- 不把「隔空硬放」当常规手段（有严格触发条件）
- 不强制站在待铺格正上方才放置

## 4. 当前完成度与缺口

- **已有**：分层领单、工位触及、寻路开门、卡住传送、工程/IDLE 强制放置、缺料/缺架气泡、完工解绑与脚手架回收、重进不误恢复已完工工程为在建；不可达/延迟剩余格与流体收尾同波放置
- **半成品 / 待打磨**：极端地形下工位与脚手架触发的边界观感；多女仆长时间互让后的吞吐
- **细节**：见各主题文；脚手架细则见 [04-脚手架与高处作业](../04-脚手架与高处作业/概览.md)

## 5. 与其它模块依赖

| 依赖模块 | 关系 |
|----------|------|
| 01-施工终端与蓝图布置 | 工程开工/暂停/完工入口与蓝图范围 |
| 02-材料仓库与补给 | 先库后背包扣料；缺料等待 |
| 04-脚手架与高处作业 | 够不着/站位失败后的搭架路径 |
| 05-工地保活与恢复 | 重登进度、不把已完工误恢复在建 |
| 06-地形清障与可覆盖物 | 放置前非蓝图占用清除；可覆盖地形策略 |
| 07-多人协作与任务分派 | 同层防抢与让出的协作语义（本模块已落地核心规则） |

## 6. 后续规划与优先级

1. 稳住「能放就放、该架再架、该跳过就跳过」的观感，减少误判隔空与误跳过脚手架
2. 工程级兜底与同层换格策略的吞吐与公平性；多女仆同时硬寻路的 tick 成本（额度已取消，需观察）
3. 与清障/材料模块联调后的玩家可感知缺口收口
