# 寻路与卡住恢复

## 要解决什么

女仆能走到工位、过门不被挡，卡住时有分级恢复而不是永久发呆。

## 期望行为

**玩家侧**：女仆会绕路、开门；卡住数秒内会换位或传送继续干，少出现对着墙点一天。

**女仆侧**：
- **原版寻路预检失败**：先走向**最近结实工位**（不当悬空几何格），再考虑脚手架（脚手架见 04 模块）
- **路径同步到女仆脑**，以触发**开门**（木门、栅栏门等）
- **施工任务免疫摔落**；**窒息 IN_WALL**：传送到就近可站立实地并**取消伤害**
- **缺架**时气泡提示，**不因缺架而隔空**（有架仍不可达才走隔空规则）

## 触发、条件与边界

### 卡住与传送（个人级）

| 情形 | 行为 |
|------|------|
| 邻域无进展或距工位不缩短约 **3 秒** | 可**传送至工位**（须已有工位；工地内无工位时不因「卡住」旁移 1～2 格）。已有工位时**不再**因垂直超过 6 格取消传送。找不到落脚点时仍不扔到建筑高度图上；同一根柱子直线上抬超过 8 格仍拒绝 |
| 目标周围没有结实工位 | 空扫结果保持约 **1 秒**，期间不再每拍重读目标旁边的空气格 |
| 工位旁 1～2 格 | **走路贴过去**（精确路径），**不瞬移**；导航结束也不会每 tick 重开一条路 |
| 全量搜路 / 脚手架全量重规划 | **无**每女仆冷却、**无**全工地每拍上限；卡住时可立刻重寻路 / 重规划 |
| 找「可走通」工位 | 候选（仅脚下结实）已按远近排好后，一次最多做约 **8** 次可达性试探；试完仍无则退回最近结实工位再走/搭架。周围没有结实工位时**不做**可达性试探，**立刻库隔空** |
| 已在工地区内、手里认领但**没有工位** | **立刻库隔空放置**（不再空转约 3 秒再松手） |
| **20 秒**无放置 | 可**兜底传送** |
| 认领超时约 **30 秒** | **必须松手**（含无工位放置失败后）；禁止只循环隔空尝试不放单 |
| 同层放置/寻路失败 | 先试**其它可放格** |
| 脚手架规划失败且够不着 / 无工位 | **无工位 → 立刻库隔空**；有工位则握住累计失败，满条件后库隔空；不因 defer 立刻松手 |
| 脚手架附近 **0.75 秒**无进展 | 升级搭架 / 传送 / 放弃（见 04） |
| 攀爬反复放架失败 | 可传送工位（见 04） |

### 寻路失败计数

- **同格寻路失败计数**每秒最多计 **1** 次
- 同格寻路失败 **≥1** 且**无工位**：可直接**库放置**（VAULT_PLACE，另需同任务卡住约 3 秒与女仆冷却，见 [强制放置与工程级兜底](./强制放置与工程级兜底.md)）
- **完全无工位**：立刻库隔空，不累计
- **有工位**够不着 / 卡住：约 **3 秒**先**传送到工位**；隔空不会抢在传送前面
- 够不着且**仍有工位** / 脚手架规划失败（有工位）：先走路或卡住传送；脚手架 escalate 路径**不再** defer 松手空转领单
- **IDLE 且未持有认领**时：不累计邻域 stall，以免关掉「换隔壁格」后反复认领同一目标

### 与脚手架

- 垂直差 **>2** 且到不了工位：**不得**误判为「跳过脚手架」
- 够不着/站位失败：**有可规划工位时先脚手架**；**完全无结实工位则立刻库隔空**；有工位卡住先传送，有架仍不可达才再考虑隔空（非 escalate 路径仍可 defer 换格并降权）

## 当前完成度与已知缺口

- **已有**：预检→工位→脚手架顺序、开门同步、分级传送（近距改为走路；无工位不旁移乒乓）、IN_WALL 救援、缺架不隔空、**无工位立刻库隔空**、够不着有工位时握住累计后隔空、全量寻路/脚手架全量重规划无额度限制、可走工位可达性试探有次数上限
- **缺口**：复杂 Redstone 门、狭窄竖井内的传送落点观感；缺料（含自动合成失败）时女仆钉在当前格等补库，气泡提示；多女仆同时硬寻路可能加重 tick（额度已取消）
