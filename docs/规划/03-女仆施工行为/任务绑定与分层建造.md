# 任务绑定与分层建造

## 要解决什么

女仆接到施工工程后，应稳定留在工地、按层推进，而不是跟随乱跑或跨层乱抢。

## 期望行为

**玩家侧**：确认开工后，绑定女仆自动「留在这里」、取消坐下、切到工作态、关闭拾取；暂停或完工后恢复跟随与拾取。

**女仆侧**：工程按**分层建造**推进；队列在**触及优先**的局部顺序下领下一格；当前层未铺完不跳到更高层（除非该层已无可领且规则允许上探）。

## 触发、条件与边界

- 开工：与工程绑定；女仆行为锁定为施工任务，免疫施工期间摔落伤害
- 分层：同一工程内按层组织待建格；领单与放置以「当前可触及层」为主；工程「起始层」以下的蓝图格不进入队列（见 [贴地覆盖与朝向旋转](../01-施工终端与蓝图布置/贴地覆盖与朝向旋转.md)）
- 触及优先：优先处理玩家/女仆已能触及范围内的局部队列，避免远层空转
- 暂停/完工：解除施工束缚，恢复跟随与拾取；完工另见 [破坏补放与完成判定](./破坏补放与完成判定.md)
- 与脚手架：垂直差大且到不了工位时，**不得**因误判而跳过脚手架流程（见 [04-何时触发](../04-脚手架与高处作业/何时触发.md)）

## 当前完成度与已知缺口

- **已有**：开工留场、WORK 态、拾取开关、分层队列、施工摔落免疫；起始层过滤待建格
- **待核实**：极多层/超大工程下的层切换观感与性能
