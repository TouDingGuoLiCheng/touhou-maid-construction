# 领单与多女仆协作

## 要解决什么

多名女仆同层施工时既要并行提速，又不能抢同一格或同一工位导致互卡。

## 期望行为

**玩家侧**：多女仆同绑一工程，应看到各干各格、少出现两女仆对同一位置反复拉扯。

**女仆侧**：
- **多女仆可同层领单**，各领不同待建格
- **他人已接管的格子/工位不可抢**
- **长时间做不完自动放弃让出**，把格子还给队列供他人领取

## 触发、条件与边界

- 领单：从当前层（及触及优先队列）取未认领格；认领前若世界已是同种蓝图方块则标已放并跳过；认领后占用该格直至放置成功、失败跳过或超时让出
- 防抢：已认领格、已选工位在他人名下时，后来者不得覆盖占用
- 让出：单格长时间无有效进展（放置、清障、脚手架推进等）则释放认领，避免独占
- 查料：走增量库存索引（按 item 加减计数）；当前层确认无有料可领时约 0.5 秒内可停扫；补料或索引变化后立刻恢复
- **存活检测预算**：有料候选按距离截断（约最近 96 格），每轮领单最多约 48 次 canSurvive；「层上是否有可放」只按库存、按方块种类判断并短缓存，**不**对每格走自动合成
- 与工程兜底：让出后格子仍可被工程级强制放置命中（见 [强制放置与工程级兜底](./强制放置与工程级兜底.md)）
- 与 07 模块：跨玩家/队伍的远期规则不在本模块展开，同工程内协作以本规则为准

## 当前完成度与已知缺口

- **已有**：同层多领、防抢、超时让出；领单查料增量索引与缺料短暂停扫；存活检测预算；层上可放按库存种类判断并短缓存；**领单跳过世界已同种的格**
- **缺口**：让出时机与玩家可感知「谁在干哪格」的 UI 反馈仍偏弱。缺料等待中大约每 10 秒重扫材料库，界面放入的物品会被认到
