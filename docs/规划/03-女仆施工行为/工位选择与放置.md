# 工位选择与放置

## 要解决什么

女仆不必站在待铺格正上方，只要在合法工位能触及并看见目标格即可稳定放置。

## 期望行为

**玩家侧**：女仆会站到旁边实心地面或已铺邻格上施工，观感接近人工选点。

**女仆侧**：
- 工位以**能放置为准**：满足**触及 + 视线**，且脚下必须是**结实落脚点**（悬空几何格不当工位）
- **优先已铺实心邻格**作为站立/工位，不要求站在待铺格正上方
- **放置触及距离约 6 格**
- 放置前：若该格**不是蓝图所需**（如长高竹子、杂草等），**强制清除并入库**后再放；**泥土与草方块互相算已满足**，不挖不换
- 材料：**先库后背包**；库与背包均不足则等待并提示（见 02 模块）；泥土/草方块材料互通见 [材料显示与别名替代](../02-材料仓库与补给/材料显示与别名替代.md)

## 触发、条件与边界

- 选工位：在目标待建格邻域搜索**脚下结实**且能触及+视线的点；悬空空气格即使几何上够得着也不当工位（**完全无实地工位则立刻库隔空**，不再空转搭架）。若还要验证「能走过去」，一次最多试探约 **8** 个候选（超出则用最近结实工位，仍没有则空）
- 放置：扣料成功 → 清障（若需要）→ 放置；`canSurvive` 等生存失败**不得**隔空死循环重试
- **四面与上方无实心依托**（空气/可替换，不查下方）：领到后立刻库放置，不要求工位
- **附近完全没有结实工位**（含侧面贴实心但仍站不稳）：同样立刻库放置
- 缺地形/外部支撑：标**失败跳过**，**不垫地基**
- 等蓝图内邻居的格：保持 **deferred**，待邻居就绪再领
- 同层放置/寻路失败：先试**其它可放格**（见 [寻路与卡住恢复](./寻路与卡住恢复.md)）
- 垂直差 **>2** 且到不了工位：**不误判跳过**脚手架流程

## 当前完成度与已知缺口

- **已有**：邻格工位（仅结实落脚点）、6 格触及、先库后背包、强制清障入库、泥土↔草方块已满足不换、deferred 与失败跳过、四面+上方空气立刻库放置（不查下方）、**完全无结实工位立刻库放置**
- **待核实**：部分模组方块视线/触及边界 case
