# 破坏补放与完成判定

## 要解决什么

施工中途被破坏的格要能补回；点完工后状态干净，重进不会把已完工工程误恢复为在建。

## 期望行为

**玩家侧**：有人拆了工地上的块，女仆会补；点「完工」后女仆解绑、临时脚手架回收，工程标记完成。

**女仆侧**：已放满/已 DONE 的格不再领单；重进加载时**不把已完工/已放满误恢复为在建**。

## 触发、条件与边界

### 破坏与补放

- 蓝图范围内、本应存在的施工块被玩家/环境破坏 → 回到待建/可领状态，由正常领单或兜底补放
- 补放遵循与新建相同的工位、材料、脚手架、跳过规则
- **每次点「开工」、以及登录自动恢复 BUILDING**：按世界实况扫一遍（忽略→跳过，**同种方块**→已放，否则→待建）；缺块进待建由女仆耗料补放，不瞬间铺块；分层仍从最低待建层领单
- **已放判定**：世界已是蓝图同一种方块即算完成（朝向、连接形状、含水干燥等属性差不拆不换）；泥土与草方块仍互认


### 点完工

- 标 **DONE**
- **解绑**施工女仆（恢复跟随、拾取等，见 [任务绑定与分层建造](./任务绑定与分层建造.md)）
- **回收脚手架**：仅回收**女仆搭建的临时架**；**蓝图自带脚手架保留**（见 [04-完工回收](../04-脚手架与高处作业/完工回收.md)）

### 重进与恢复

- 已 **DONE** 的工程：保持完成态，不重新开工
- 已放满、与蓝图**同种方块**的格：不当作「未建」重新领单（不要求属性完全一致）
- 细节持久化与区块策略见 **05-工地保活与恢复**

## 当前完成度与已知缺口

- **已有**：DONE 解绑、临时架回收、重进不误恢复已完工/已放满；**开工/登录扫缺**把世界缺块重新进待建；**同种方块不算缺**，领单前再对世界确认

- **缺口**：部分边界（卸载区块内破坏、非挖掘/爆炸破坏）依赖保活与事件覆盖
