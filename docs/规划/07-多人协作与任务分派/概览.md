# 多人协作与任务分派

## 1. 定位与目标

本模块管「同一工地上，多名施工女仆怎么分活、怎么不抢、怎么让路」。  
成功标准：多女仆同层能并行推进；已被他人接管的格子与工位不被抢走；长时间做不完会自动放弃让出；大工程刷新不拖垮服务器。

## 2. 玩家体验 / 玩法流程

玩家把多名女仆绑到同一工程后，她们在**当前层**各自领格子施工。  
玩家侧几乎无额外操作：看不到公会面板或跨玩家任务板，只感到「人多了更快、少打架、偶尔有人换目标」。

## 3. 内容边界

### 做
- 同工地、同层多女仆领单与并行
- 格子 / 工位占用互斥（防抢）
- 长时间未完成则放弃并让出，供他人接手
- 大工程队列刷新限流，避免 TPS 崩

### 不做
- 完整跨玩家公会 / 队伍任务系统（远期愿景，当前不做）
- 跨层分工编排（同层协作；层间另有建造节奏）
- 玩家手动指派「谁做哪一格」的细粒度 UI

## 4. 当前完成度与缺口

| 状态 | 说明 |
|------|------|
| 协作核心 | **已有**：同层领单（由近及远分拍）、防抢、工位占用与超时让出、队列刷新限流 |
| 跨玩家 / 队伍 | **弱 / 远期**：无公会规则、无队伍可见性与权限模型；主题文单独标愿景 |
| 体验打磨 | 偶发「都在让出 / 都在绕路」等边缘节奏，需靠联调与日志观察，非功能空白 |

诚实结论：**同工地多女仆协作可用；不是完整多人社交协作系统。**

## 6. 后续规划与优先级

1. **稳住现有同工地协作**（防抢 + 让出 + 限流）— 优先验收与回归  
2. **边缘节奏**：长时间让出是否过频、工位互让是否导致空转  
3. **远期**：跨玩家 / 队伍可见性与权限（明确不进当前排期）
