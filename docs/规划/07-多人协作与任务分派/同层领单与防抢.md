# 同层领单与防抢

## 要解决什么

同一工地上多名女仆同时施工时，既要并行推进，又不能抢别人已在做的格子。

## 期望行为

**玩家侧**  
绑定多名女仆到同一工程后，她们在当前层各自领活；不会出现两人反复抢同一格、来回拆放。

**女仆侧**  
- 空闲时从工程队列领**当前层**可做的下一格（或就近一批）。  
- 领单以自身（或上次放置点）为中心**由近及远**找有料可放的格子；大层不会一次扫完全层，而是分多拍向外扩。  
- **好做的先做**：在就近一批候选里按「好做程度」加权——附近有实地落脚点权重最大，其次是下方有支撑、四周/上方贴着已有方块；悬空、四面无依托的边缘格排到本批最后，等周边建起来再做。同分仍按远近。  
- 第一次领单优先挑工位没被别人站着的格；**一个工位都没有的格算「拥挤」**，不再和好站的格同等对待。占位判断用小范围实心落脚探测（不做整圈视线搜工位），避免多女仆领单拖死 tick。
- 已被其他女仆接管的格子视为占用，**不可再领**。  
- 同层并行：不同女仆可各做不同格，整体进度加快。  
- **不跨层抢单**：层间建造节奏由分层逻辑管，本主题只管同层协作。

## 触发、条件与边界

- **领单时机**：女仆空闲、有材料 / 脚手架条件、目标格在本层且未被占用。  
- **防抢**：一旦某格被某女仆接管，其他女仆领单时跳过该格，直到占用释放（完成、放弃、让出）。  
- **工位与格子**：若某格需要特定站位（含脚手架工位），站位占用与格子占用一致——他人已占则不可抢。  
- **边界**：仅同工地、同工程内的女仆共享队列；**不**含跨玩家权限、跨服同步。  
- **大工程**：队列刷新有频率上限（每 job 每秒最多一次）；领单查料按「雷达」预算向外扩（每拍有上限，跨拍续扫），整圈仍无料才短暂停扫，避免每 tick 全层查料卡顿。

## 当前完成度与已知缺口

- **已有**：同层领单、占用互斥、他人已接管不可抢；与女仆施工行为、脚手架工位语义打通；大层领单查料改为由近及远分拍扫描；就近候选按好做程度加权、无工位格视为拥挤。  
- **缺口 / 待核实**：  
  - 加权只在就近一批候选内生效；若整批都是悬空格（如纯挑檐层），**完全无结实工位的格立刻库放置**（四面+上方全空气的仍走孤立空气快路径；侧面贴实心但站不稳的同样立刻库放置）。
  - 「上次放置点」只存内存，重进后领单中心回到女仆脚下（待持久化）。  
  - 极密集工地下，多女仆同时雷达扫是否偶发「都先看近处无料圈」的短暂空转——体验级。  
  - 与「让出」联动的边界：刚让出的格是否立刻可被他人领走（预期是）。  
- **明确不做**：跨玩家可见「这是谁的单」、手动转单、队伍优先级。
