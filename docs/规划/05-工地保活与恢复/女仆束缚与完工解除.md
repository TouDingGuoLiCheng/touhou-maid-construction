# 女仆束缚与完工解除

## 要解决什么

施工期间女仆应**留在工程语境**内（束缚 / 绑定），避免闲逛、跟随或接别的任务；工程**完工**后应**立即解除**束缚并同步终态，防止重登或 AI  tick 再次把女仆拉回旧工地。

## 期望行为

**施工中：** 女仆与当前工程绑定，行为层以工地任务为优先（细节见模块 03）。

**点完工 / 自动完工：** 工程状态同步为 **DONE**；女仆**解除束缚**；工作模式切回**空闲**；不再对该工程领单或恢复。

**防误恢复：** 若工程已标记完工，或世界中蓝图格已全部正确放置，任何「恢复在建」路径都不应再激活。

## 触发、条件与边界

- 真正结束包括：方块放完**自动完工**，或玩家终端 Hub **强制完工**。
- DONE 与束缚解除、工作模式回空闲应**同一逻辑批次**生效，避免「状态已完工但女仆仍被束缚 / 仍挂施工任务」或相反。
- 暂停工程**不**切回空闲（仍挂施工任务，便于再开）。
- 重登恢复链路必须读取 DONE / 已放满判定，**短路**恢复。
- 本主题不定义「如何判断单格已正确放置」——沿用 project / 施工完成判定（模块 03）。

## 当前完成度与已知缺口

- **已有：** 完工同步 DONE；解除束缚；工作模式回空闲；已完工 / 已放满不误恢复在建。
- **需进游戏回归：** 完工后再进存档，女仆不被拉回旧工地（与 `下一步的计划-可覆盖地形含花草树木.md` 阶段 3 一致，待勾验收项）；自动/强制完工后 GUI 工作模式为「空闲」。
