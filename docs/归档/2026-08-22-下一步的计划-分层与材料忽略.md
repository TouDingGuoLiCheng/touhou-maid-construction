# 下一步的计划 · 车万女仆：施工队 — 分层建造 / 材料忽略 / 创造补料

> **For agentic workers:** 按阶段验收推进；每完成一阶段将对应 `- [ ]` 改为 `- [x]`。全部完成后按工作区规则归档到 `docs/归档/`。

**Goal:** 重写施工调度为「蓝图相对高度分层」；修复假缺料横跳与脚下塞块卡死；工程页可忽略/恢复材料类型；创造模式一键填满材料库。

**Architecture:** `BlueprintTaskBuilder` 为每块标注 `layerIndex`（蓝图内最低非空气 Y = 0）→ `BuildJob` 仅开放当前最低未完成层 → 层内先实心后附着，附着失败标 `deferred` → 层完成条件：未忽略、未延后的可放置块全部处理完 → 工程收尾统一补放 `deferred`；`BuildProject` 持久化 `ignoredBlockIds`；Hub 第 2 页悬停忽略/恢复 + 创造模式「一键导入材料」。

**Tech Stack:** Minecraft 1.20.1 / Forge 47.x；Java 17；硬依赖 Touhou Little Maid。

## Global Constraints

- **禁止**擅自修改 `gradle.properties` 的 `mod_version`
- 玩家可感知改动写入 `版本改动.md`（当前版本下）
- 多女仆：**同层抢单，不跨层**
- 忽略材料：该方块类型全局不放置、不扣料；同格可恢复
